🎮 Movement & Grounding Test

Test Checklist:

✓ Player starts on ground TESTING
✓ No constant jumping TESTING
✓ Jump only when key pressed (not held) TESTING
✓ Player stays grounded when idle TESTING
✓ Enemies stay on ground TESTING

Instructions:

  1. Click "Start Test" to load the game
  2. Enter a player name when prompted
  3. Watch for automatic jump detection
  4. Press W/Space once - should jump ONCE, not repeatedly
  5. Hold W/Space - should NOT keep jumping
  6. Use A/D to move left/right
  7. Stand still - character should stay on ground
  8. Check enemies - they should walk on platforms, not float

Controls: A/D = Move, W/Space = Jump, Z = Attack, X = Spare
